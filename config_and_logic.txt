3. APPLICATION LOGIC & BUSINESS RULES
--------------------------------------------------------------------------------

3.1 Main Execution Flow (MainApp.java)
  - Entry point initializing OrderProcessor, InvoiceProcessor, and CustomerReportService.
  - Creates a sample item list: ["Laptop", "Mouse", "Keyboard"].
  - Triggers processOrder(), processPriorityOrder(), generateInvoice() with $1,200.00 base amount for VIP customer type.
  - Triggers generateReport() with null file path, type 50, and flags set to true.
  - Displays summary of results.

3.2 Order & Invoice Processing Logic (OrderProcessor.java & InvoiceProcessor.java)

  A. Input Validation Logic:
     - Check 1: Amount must be > 0 (throws IllegalArgumentException if invalid).
     - Check 2: Customer type must be non-null and non-empty (throws IllegalArgumentException if invalid).
     - Check 3: Items list must be non-null and non-empty (throws IllegalArgumentException if invalid).

  B. Discount Calculation Logic:
     - Customer Type "VIP"      : 20% discount (amount * 0.20)
     - Customer Type "PREMIUM"  : 15% discount (amount * 0.15)
     - Customer Type "REGULAR"  : 5% discount (amount * 0.05)
     - Other / Default          : 0% discount

  C. Tax & Shipping Calculation Logic:
     - Taxable Amount = Base Amount - Discount
     - State Tax      = Taxable Amount * 7.5% (0.075)
     - Federal Tax    = Taxable Amount * 2.5% (0.025)
     - Total Tax      = State Tax + Federal Tax
     - Shipping Fee   = $15.00 if Taxable Amount <= $500.00, otherwise $0.00 (Free Shipping)
     - Final Total    = Taxable Amount + Total Tax + Shipping Fee

  D. Output Formatting & Reporting:
     - Logs detailed breakdown of Customer Type, Base Amount, Discount, Taxable Amount, Total Tax, Shipping Fee, and Final Total formatted to 2 decimal places.

3.3 Report Generation Logic (CustomerReportService.java)

  A. Deeply Nested Validation (Cognitive Complexity Smell):
     - Validates filePath is non-null, non-empty, reportType between 1 and 99, and flags (flag1, flag2, flag3) are true.

  B. File Processing & Maintenance Smells:
     - Attempts to read from specified filePath (defaults to "dummy.txt" if null).
     - Appends " - PROCESSED" to each line using String concatenation inside loop.
     - Catches IOException and NullPointerException with empty catch blocks (exception swallowing).

  C. Time Calculation Logic:
     - x = 86400 (seconds in a day)
     - y = 3600 (seconds in an hour)
     - z = x + y * 24 (total calculated seconds)
